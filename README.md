# 🌟 NOUR : RETROUVE TA LUMIÈRE (نُور)
### RPG Initiatique Éthique & Éducatif — La Trilogie Complète (v2.0)

> **« Ce jeu n'a de valeur que s'il transforme la vie réelle du joueur. »**  
> Une aventure spirituelle, poétique et humaine inspirée des contes orientaux et de la sensibilité du studio Ghibli, mariant pixel-art rétro, développement personnel, Adab prophétique et actions concrètes dans le monde réel (*Life-RPG*).

## 🎮 Où et Comment Jouer ?

### 1. 📱 Version Mobile Android (APK Autonome)
Le fichier APK complet est compilé et disponible à la racine du projet :
- **Fichier** : `Nour-LaVoieDeLaSagesse-debug.apk` (61.8 Mo)
- **Installation** : Transférez le fichier sur votre smartphone/tablette Android, autorisez l'installation d'applications de sources inconnues et profitez de l'expérience hors-ligne complète.

### 2. 🌐 Version Web Progressive (PWA)
Jouez directement depuis n'importe quel navigateur (PC, Mac, iPhone, iPad, Android) :
- **Lien officiel** : [https://nour-le-jeux.web.app](https://nour-le-jeux.web.app)

## 📖 Vous ne pouvez pas jouer sur écran ? (Livre Interactif & Dossier Pédagogique)

Pour les parents, éducateurs, personnes malvoyantes (synthèse vocale) ou lecteurs qui ne peuvent pas jouer sur écran, **l'intégralité du jeu a été retranscrite mot à mot** dans le dossier :

👉 **[`RAPPORT_INTEGRAL_NOUR.md`](./RAPPORT_INTEGRAL_NOUR.md)** (1900+ lignes de dialogues, choix et sagesse) :
- **Chapitre 1 : Le Premier Pas vers l'Autre** (L'éveil, la timidité, le Salām, le refus, le don secret et le jardin réhabilité).
- **Chapitre 2 : Le Chemin du Hilm** (La colère, l'accusation au marché des grenades, l'eau des ablutions, la bifurcation entre le geste de douceur *Ar-Rifq* et la *Duʿāʾ secrète*, le duel du Hilm).
- **Chapitre 3 : La Montagne Intérieure** (La maladie, l'apothicaire, l'enfant à l'attelle, la Talbîna et le miel, la cueillette sous les amandiers ou le manuscrit d'Ayyūb, le bouillon chaud du voisin, la graine sous terre, le duel contre l'abandon).
- **Toutes les micro-actions dans la vraie vie** (*ranger son lit, boire avec Adab, pardonner, visiter les malades*).
- **Synthèse théologique intégrale** avec tous les Hadiths (Bukhari, Muslim, Tirmidhi, Abu Dawud) et versets coraniques en arabe et français.

## 💻 Développement & Lancement Local

```bash
# 1. Installer les dépendances
npm install

# 2. Lancer le serveur de développement local
npm run dev

# 3. Compiler la version Web de production
npm run build

# 4. Synchroniser avec Capacitor Android
npx cap sync android

# 5. Compiler l'APK Android
cmd.exe /c android\build_apk.bat
```
